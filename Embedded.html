The announcement extends Synopsys’ AI-driven EDA portfolio beyond task-level automation by introducing autonomous workflows that execute long-running engineering processes with minimal human intervention. Built on the company’s AgentEngineer technology, the platform combines domain-specific AI agents with task-oriented agents to coordinate multiple stages of chip development while leveraging Microsoft Azure cloud infrastructure.

Among the new capabilities is a fully autonomous debug closure workflow that automates verification and root cause analysis (RCA). The workflow identifies design failures, performs debugging, and supports validation by orchestrating multiple AI agents via Microsoft Discovery. According to Synopsys, initial evaluations indicate reductions in debug cycle time of 25% to 40%, potentially eliminating several weeks of engineering effort while improving verification productivity and silicon quality.

The second workflow focuses on physical implementation and design closure. It integrates Synopsys implementation agents with the company’s Fusion Compiler running on Microsoft Azure to automate quality-of-results (QoR) optimization during implementation. By coordinating multiple AI agents, the workflow performs iterative tuning and closure tasks that traditionally require extensive engineering intervention. Early evaluations have shown measurable improvements in implementation QoR.

The new workflows build on the ongoing collaboration between Synopsys, AMD, and Microsoft to apply large-scale AI reasoning, semiconductor design expertise, and cloud computing resources to the development of next-generation AI infrastructure devices. They also extend previous work on an AI-assisted specification-to-register-transfer-level (RTL) design flow, representing the first EDA applications available for evaluation through the Microsoft Discovery platform. AMD is currently assessing autonomous workflows for use in developing future semiconductor products.

Synopsys is demonstrating new AI-powered engineering capabilities at the 2026 Design Automation Conference (DAC), showcasing how autonomous workflows can improve design efficiency, accelerate development cycles, and enhance engineering productivity from silicon design through to complete electronic systems.
